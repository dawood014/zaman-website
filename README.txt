Open index.html to browse the website.
Open admin.html for the static admin-panel demo.

IMPORTANT STATIC-DEMO NOTES
- The admin panel uses browser localStorage. Property and contact changes are visible on public pages in the same browser.
- Email buttons use mailto: links and open the visitor's email client.
- WhatsApp buttons use wa.me links. Set the real WhatsApp number in admin.html > Website Settings.
- Property images currently use remote demo images. Replace them with approved project/property photographs when available.
- Google Maps location is configured for Zaman Villas, Green Lodges near Pir Bala Police Station, Warsak Road, Peshawar.
